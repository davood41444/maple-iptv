# Maple IPTV برای آیفون و آیپد

اپ آیفون همان صفحه‌های اپ اندروید را نشان می‌دهد (پوشه‌ی `web/`)، با این تفاوت‌ها:
- **پخش‌کننده:** موتور پخش **VLC** است، پس این‌ها کار می‌کنند: MKV، کانال‌های زنده‌ی TS و HLS، زیرنویس، چند زبان صدا، و صدای AC3 و DTS.
- **پرداخت:** پرداخت فقط با **خرید داخل اپ اپل** است، چون قانون اپل همین است. کدهایی که از سایت خریده شده‌اند هم کار می‌کنند و سقف ۳ دستگاه برایشان برقرار است.
- **دوره‌ی آزمایشی:** ۷ روز است و در Keychain آیفون ذخیره می‌شود. پس با پاک کردن و نصب دوباره‌ی اپ، از اول شروع نمی‌شود.

## فایل‌ها

| فایل | کار |
|---|---|
| `project.yml` | تعریف پروژه‌ی Xcode. پروژه با `xcodegen` از روی این فایل ساخته می‌شود |
| `Podfile` | موتور پخش VLC (MobileVLCKit) |
| `MapleIPTV/MainViewController.swift` | صفحه‌ی اپ، ویدیو زیر آن، و پیام‌های بین صفحه و آیفون |
| `MapleIPTV/HostScript.swift` | همان رابط `AndroidHost` اپ اندروید، برای آیفون |
| `MapleIPTV/AppSchemeHandler.swift` | فایل‌های اپ، و پروکسی برای دریافت پلی‌لیست‌ها |
| `MapleIPTV/NativePlayer.swift` | پخش با VLC: ترک‌های صدا و زیرنویس، اندازه‌ی تصویر |
| `MapleIPTV/Billing.swift` | اشتراک App Store با StoreKit 2 |
| `../.github/workflows/ios.yml` | ساخت ابری روی مک GitHub |

## ساختن فایل آیفون (بدون مک)

ساختن اپ آیفون فقط روی مک ممکن است. به‌جای مک، GitHub یک مک ابری رایگان در اختیار می‌گذارد.

این کار راه‌اندازی شده است. پروژه در مخزن خصوصی https://github.com/davood41444/maple-iptv است و ساخت ابری موفق است.
- فایل `.gitignore` جلوی فایل‌های خصوصی را می‌گیرد: کلید کوپن‌ها، تنظیمات این کامپیوتر و فایل‌های ساخته‌شده.

1. **اجرای ساخت:** با هر تغییر در پوشه‌ی `ios/` خودکار شروع می‌شود. برای اجرای دستی: **Actions ← iPhone app ← Run workflow**.
2. **دریافت فایل:** چند دقیقه بعد، فایل `MapleIPTV-iPhone-unsigned` (یک فایل .ipa) در پایین صفحه‌ی همان ساخت آماده است.

جزئیات بیشتر در [docs/GITHUB.md](../docs/GITHUB.md) است.

## نصب روی آیفون

**راه ۱: TestFlight (پیشنهادی)**
- لازم دارد: حساب **Apple Developer** (سالی ۹۹ دلار آمریکا).
- اپ را از برنامه‌ی TestFlight اپل روی آیفون خودتان و تا ۱۰٬۰۰۰ آزمایش‌کننده نصب می‌کنید.
- قدم بعدی بعد از آن، انتشار در App Store است.

**راه ۲: AltStore یا Sideloadly با Apple ID رایگان (فقط برای امتحان)**
- برنامه‌ی AltStore را روی ویندوز نصب کنید، آیفون را با کابل وصل کنید و فایل .ipa را با Apple ID خودتان نصب کنید.
- Apple ID را خودتان وارد کنید.
- اپ نصب‌شده هر ۷ روز باید دوباره نصب شود. برای مشتری‌ها مناسب نیست.

## راه‌اندازی App Store (یک بار، بعد از ساختن حساب Apple Developer)

1. **ثبت اپ:** در App Store Connect یک اپ با Bundle ID برابر `com.mapleonlinesolutions.iptv` بسازید.
2. **اشتراک‌ها:** در بخش **Subscriptions** یک Subscription Group بسازید (مثلاً «Maple Premium») و دو اشتراک خودکار با همین شناسه‌ها در آن بسازید:
   - `maple_premium_monthly`: ماهانه، ۳.۹۹ دلار
   - `maple_premium_yearly`: سالانه، ۳۹.۹۹ دلار
3. **کلید API:** در **Users and Access ← Integrations ← App Store Connect API** یک کلید با نقش **App Manager** بسازید.
4. **رمزهای GitHub:** در مخزن GitHub به **Settings ← Secrets and variables ← Actions** بروید و این ۴ مورد را **خودتان** وارد کنید:
   - `ASC_KEY_ID`: شناسه‌ی کلید
   - `ASC_ISSUER_ID`: Issuer ID
   - `ASC_KEY_P8`: متن کامل فایل .p8
   - `APPLE_TEAM_ID`: Team ID حساب اپل (در Membership)
5. **ارسال به TestFlight:** در Actions، اجرای «iPhone app» را با تیک **testflight** بزنید. نسخه‌ی امضاشده مستقیم به TestFlight می‌رود.
6. **اطلاعات بررسی اپل:** برای ارسال به App Store، این‌ها را آماده کنید:
   - لینک حریم خصوصی: `https://mapleonlinesolutions.com/maple-iptv/privacy`
   - لینک شرایط: `https://mapleonlinesolutions.com/maple-iptv/terms`
   - یک **پلی‌لیست نمایشی قانونی** برای بازبین اپل. بازبین باید بتواند اپ را بدون کانال‌های واقعی امتحان کند.

## نکته‌ها

- **آزمایش‌نشده روی آیفون واقعی:** ساخت ابری بدون خطا و هشدار انجام می‌شود، ولی اپ هنوز روی آیفون واقعی اجرا نشده است. ارتباط صفحه با آیفون (پخش، اشتراک، اندازه‌ی ویدیو، اطلاعات دستگاه) را در مرورگر شبیه‌سازی و آزمایش کرده‌ام.
- **کوپن‌های رایگان:** قانون اپل باز کردن امکانات با کدهای غیر از خرید اپل را محدود می‌کند. کدهای خریدشده از سایت مجازند، چون همان اشتراک داخل اپ هم موجود است. کوپن‌های رایگان (`tools/coupons.js`) ممکن است در بررسی اپل مشکل‌ساز شوند. اگر اپل ایراد گرفت، در نسخه‌ی آیفون فقط کدهای MPL- را قبول می‌کنیم.
- **نسخه:** `MARKETING_VERSION` در `project.yml` است و هم‌زمان با بقیه‌ی پلتفرم‌ها عوض می‌شود. شماره‌ی ساخت را GitHub خودش بالا می‌برد.
