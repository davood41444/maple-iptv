# راهنمای GitHub برای Maple IPTV

این راهنما برای کسی است که تا حالا با GitHub کار نکرده.

## GitHub چیست و این پروژه آنجا چه می‌کند؟

GitHub جایی برای نگه‌داری کد پروژه‌ها روی اینترنت است. برای Maple IPTV سه کار انجام می‌دهد:

1. **نسخه‌ی پشتیبان:** همه‌ی کدها و راهنماها آنجا امن نگه داشته می‌شوند. هر تغییر هم با تاریخ ثبت می‌شود و هر وقت بخواهید، می‌شود به نسخه‌ی قبلی برگشت.
2. **ساختن فایل آیفون:** اپ آیفون فقط روی مک ساخته می‌شود. GitHub یک مک ابری دارد که این کار را رایگان انجام می‌دهد (بخش **Actions**).
3. **یک صفحه برای پروژه:** صفحه‌ی اصلی پروژه همان فایل [README.md](../README.md) است که توضیحات و لینک همه‌ی راهنماها را دارد.

پروژه **خصوصی (Private)** است: فقط خودتان و کسانی که دعوت کنید آن را می‌بینید.

**چیزهایی که در GitHub نیست:**
- کلید امضای کدهای هدیه (`tools/coupons/`)
- فایل‌های ساخته‌شده‌ی اپ (`dist/`)
- تنظیمات این کامپیوتر
- پروژه‌ی سایت اصلی (MapleOS): رمزهای سرور و دیتابیس دارد و جدا نگه داشته می‌شود

## بخش‌های صفحه‌ی پروژه

صفحه‌ی پروژه این آدرس است: https://github.com/davood41444/maple-iptv

| بخش (بالای صفحه) | چه چیزی دارد |
|---|---|
| **Code** | فایل‌ها و پوشه‌ها. پایین صفحه توضیحات پروژه (README) نشان داده می‌شود |
| **Actions** | ساختن خودکار اپ آیفون. هر ساخت یک ردیف است: سبز یعنی موفق، قرمز یعنی خطا |
| **Settings** | تنظیمات پروژه، از جمله رمزهای اپل برای TestFlight (Secrets) |

## ساختن فایل آیفون

1. **ساخت خودکار:** وقتی کد مخصوص آیفون (پوشه‌ی `ios/`) تغییر کند، ساخت خودکار شروع می‌شود.
2. **ساخت دستی:** برای بقیه‌ی تغییرات، مثلاً یک نسخه‌ی جدید، از **Actions ← iPhone app ← Run workflow ← Run workflow** (دکمه‌ی سبز).
   - حساب رایگان GitHub برای پروژه‌های خصوصی ماهانه حدود ۲۰۰ دقیقه مک ابری می‌دهد، یعنی حدود ۱۳ بار ساخت.
   - برای همین ساخت فقط وقتی لازم است انجام می‌شود.
3. **صبر:** ساخت حدود ۱۰ تا ۱۵ دقیقه طول می‌کشد. دایره‌ی زرد یعنی در حال ساخت است.
4. **دریافت فایل:** وقتی تیک سبز شد، روی همان ردیف کلیک کنید. پایین صفحه، در بخش **Artifacts**، روی **MapleIPTV-iPhone-unsigned** کلیک کنید. یک فایل zip دانلود می‌شود که فایل `.ipa` داخلش است.
5. **اگر قرمز شد:** به من بگویید. خطا را می‌خوانم و درستش می‌کنم.

برای نصب این فایل روی آیفون، [ios/README.md](../ios/README.md) را ببینید (TestFlight یا AltStore).

## افزودن رمزهای اپل (برای TestFlight)

فقط بعد از ساختن حساب Apple Developer لازم است:

1. به **Settings ← Secrets and variables ← Actions ← New repository secret** بروید.
2. این چهار مورد را یکی‌یکی بسازید. نام دقیقاً همین‌ها باشد و مقدار را **خودتان** وارد کنید:
   - `ASC_KEY_ID`
   - `ASC_ISSUER_ID`
   - `ASC_KEY_P8`
   - `APPLE_TEAM_ID`
3. بعد در **Actions ← iPhone app ← Run workflow**، تیک **testflight** را بزنید.

رمزها بعد از ذخیره دیگر قابل دیدن نیستند، حتی برای خودتان. این برای امنیت است.

## تغییرات بعدی

تغییرات کد را من روی همین کامپیوتر انجام می‌دهم و با اجازه‌ی شما در GitHub بارگذاری می‌کنم. لازم نیست خودتان کاری در GitHub انجام دهید، جز دانلود فایل آیفون و وارد کردن رمزها.

## امنیت حساب GitHub

- **ورود دومرحله‌ای (2FA):** حتماً روشنش کنید: **Settings شخصی ← Password and authentication**. GitHub برای حساب‌های جدید آن را لازم می‌داند.
- **کدهای بازیابی (Recovery codes):** جای امنی نگه دارید.
- **رمز:** رمز GitHub را به هیچ‌کس، از جمله من، ندهید. هر بار که ورود لازم باشد، خودتان در صفحه‌ی GitHub وارد می‌شوید.
